# Expense Tracker

A React-based expense tracker application that helps users manage their income and expenses, track transactions, and monitor their balance.

## Features

- Add new income and expense transactions
- Delete existing transactions
- Calculate total income and expenses automatically
- Display the current balance
- Form validation to prevent invalid entries
- Dynamic transaction list

## Built With

- React
- JavaScript
- HTML
- CSS
- Vite

## React Concepts Practiced

- Functional Components
- Props
- useState
- Array Methods (`map`, `filter`, `reduce`)
- Event Handling
- Controlled Components
- Form Validation

## Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/AlpayDevv/react-expense-tracker.git
   ```

2. Navigate to the project folder:

   ```bash
   cd expense-tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
